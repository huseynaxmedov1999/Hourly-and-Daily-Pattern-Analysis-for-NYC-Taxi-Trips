# <p align = center> _NYC Taxi Trips Analysis_

### Project Overview

- This project analyzes hourly and daily transportation patterns in New York City taxi trips using Python and data visualization techniques. The analysis focuses on identifying peak demand periods, trip duration behavior, traffic trends, and temporal transportation patterns across different hours, days, and months.

- The project includes exploratory data analysis (EDA), outlier handling, and visualization of NYC taxi activity.

### Exploratory Data Analysis (EDA)

**Performed:**

- Hourly trip analysis
- Daily trip analysis
- Monthly duration analysis
- Distribution analysis
- Peak hour identification

### Conclusion

- This analysis provides valuable insights into NYC transportation behavior and taxi demand patterns. The findings can help better understand traffic congestion, peak travel periods, and customer mobility trends across New York City.
